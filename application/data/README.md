# Données cartographiques

`provinces_45_2017.geojson` contient les limites simplifiées des 45 provinces du Burkina Faso selon le référentiel 2017.

- Source : geoBoundaries API, jeu `BFA-ADM2-67063806`.
- Producteur indiqué : World Bank.
- Licence : Creative Commons Attribution 4.0.
- URL de métadonnées : https://www.geoboundaries.org/api/current/gbOpen/BFA/ADM2/

Ce fichier sert à la visualisation historique. Il ne représente pas les deux provinces créées lors de la réforme de 2025.
