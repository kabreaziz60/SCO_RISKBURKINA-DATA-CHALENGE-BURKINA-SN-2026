# Règles de confidentialité

1. Les données du challenge restent sur l'ordinateur de l'équipe.
2. Aucun classeur, extrait de ligne, rapport détaillé ou fichier nettoyé n'est envoyé à un outil d'intelligence artificielle.
3. Les scripts locaux peuvent calculer des contrôles agrégés. Ils ne doivent pas afficher de valeurs de cellules dans le terminal.
4. Toute aide extérieure porte sur le code, la méthode, des données fictives ou des résultats dont le partage est expressément autorisé.
5. Avant un dépôt, une personne vérifie le fichier, sa source, sa finalité et son niveau de confidentialité.
6. Les données sont utilisées uniquement dans le cadre du concours.

Le guide autorise l'aide d'une IA après le nettoyage et la préparation, avec esprit critique et transparence sur l'usage qui en a été fait. Cette aide ne permet jamais de transmettre les données sensibles.
